# 🤖 AI Content Summarizer

A Python application that uses Natural Language Processing (NLP) and Hugging Face Transformers to summarize long YouTube videos and web articles within seconds.

---

## 🌟 Features
- **YouTube Support:** Extracts auto-generated or manual transcripts from YouTube video links.
- **Web Scraping:** Parses text paragraphs from any blog or news article URL.
- **AI-Powered:** Uses the `facebook/bart-large-cnn` transformer model for high-quality abstractive text summarization.

---
